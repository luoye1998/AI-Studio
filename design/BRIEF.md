# WorkStream Studio · 视觉规范（BRIEF）

## 1. 一句话
给专业创作者用的、深色电影感的 AI 影视生产流水线。**信息密度高，但不拥挤；装饰极少，靠留白与细线建立秩序。**

## 2. 色彩令牌

| 语义 | 值 | 用途 |
|---|---|---|
| `--bg` | `#07080B` | 应用底色 |
| `--bg-soft` | `#0A0C11` | 侧栏 |
| `--surface` | `#0D1016` | 卡片 |
| `--surface-2` | `#12161F` | 浮层 / 模态 |
| `--surface-3` | `#171C27` | 悬停态 |
| `--line` | `rgba(255,255,255,0.075)` | 常规分隔线 |
| `--line-strong` | `rgba(255,255,255,0.14)` | 可交互边界 |
| `--text` | `#E9ECF3` | 主文字 |
| `--text-2` | `#A9B2C3` | 次文字 |
| `--text-3` | `#6C7488` | 弱文字 / 标签 |
| `--gold` | `#E0B055` | 品牌主色（进度、主按钮、锁定） |
| `--gold-soft` | `rgba(224,176,85,0.12)` | 主色底 |
| `--indigo` | `#7B8CFF` | 次强调（信息、进行中） |
| `--green` | `#45D69B` | 成功 / 已锁定 |
| `--amber` | `#F0A742` | 警告 / 待审阅 |
| `--red` | `#FF6B6B` | 危险 / 打回 |

**禁止**：紫色 / 粉色渐变、纯黑 `#000`、纯白 `#FFF` 大面积、超过 3 个颜色的渐变。

## 3. 字体
- 中文 / 正文：`Inter, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 数字 / 代码 / 计时：`"SF Mono", "JetBrains Mono", ui-monospace, Consolas, monospace`
- 字号阶梯：10 / 10.5 / 11.5 / 12.5 / 13.5 / 16 / 20（px）；行高 1.6–1.8
- 标题字重 620，正文 400，数字一律 tabular-nums

## 4. 圆角与阴影
| 令牌 | 值 |
|---|---|
| `--r-sm` | 8px |
| `--r-md` | 12px |
| `--r-lg` | 18px |
| `--r-xl` | 24px |
| `--shadow-1` | `0 1px 2px rgba(0,0,0,.4)` |
| `--shadow-2` | `0 12px 32px rgba(0,0,0,.45)` |
| `--shadow-3` | `0 32px 80px rgba(0,0,0,.6)` |

阴影只在浮层（模态、Toast、画布节点）用；平面卡片用 **1px 细边框**代替阴影。

## 5. 间距
4 的倍数：4 / 6 / 8 / 10 / 12 / 16 / 18 / 22 / 28 / 40。卡片内边距 16，页面横向留白 22。

## 6. 图形语言
- 图标：24×24 网格，1.6 描边，圆头圆角，**只用描边不用填充**（除极小的点）
- 插画：线性为主 + `--gold-soft` 低透明度块面，**不做彩色插画**
- 品牌图形：金色渐变 `#F0CD82 → #C9932F → #8A5F16`，深色底反白

## 7. 动效原则
- 时长 150–200ms，缓动 `cubic-bezier(.2,.8,.3,1)`
- 只动 `transform` / `opacity`
- 状态变化用**颜色**表达，不用位移和缩放
- 危险操作：红底、需二次确认；成功：绿勾，不弹大图

## 8. 文案语气
短句、动词开头、不用感叹号。例如「生成初稿」「确认采用」「解锁重做」；不要「快来试试吧！」。
