# WorkStream Studio 设计系统

> 深色电影感工作台：金色是导演笔，靛蓝是机器，绿 / 琥珀 / 红只回答状态。

## 设计语言

- 深色电影感：`#07080B` 底，两团极淡的金与靛蓝径向光晕；层级靠表面明度（`#0D1016 → #12161F → #171C27`）与 1px 细边框，而不是大色块。
- 主色：低饱和金 `#E0B055` 用于主操作、金额、选中与锁定完成；靛蓝 `#7B8CFF` 用于信息、草稿与辅助。
- 语义色：绿 `#45D69B` 成功 / 锁定，琥珀 `#F0A742` 待审 / 警示，红 `#FF6B6B` 危险 / 打回。
- 数字：金额、秒数、编号、时间统一用 `--mono` + `tabular-nums`，表格里能对齐。
- 字体：正文 13.5px / 1.6；标题 620 字重；小标签 10px 大写、字距 .14em；中文优先 PingFang / 微软雅黑。
- 质感：细边 `rgba(255,255,255,.075)`、强调线 `.14`；阴影只给浮层与节点，不用于表达状态。

## 组件清单

- 按钮：4 种变体——默认（白 4.5% 底 + 细边）、`primary`（金色渐变 + 深色字）、`ghost`（透明）、`danger`（红底红字）；另有 `ok`（绿）与 `on`（金选中）语义态。尺寸默认 30 / `sm` 26 / `lg` 36，`block` 撑满，图标 14px。
- 标签 Tag：6 种语义色——默认、gold、green、red、amber、indigo；胶囊 21px、字号 10.5，可带 5px 状态点。
- 卡片 Card：表面色 + 1px 边 + 18 圆角，`pad` 内边距 16；组合含资产卡、统计块、键值行、DAG 节点。
- 进度 Progress：4px 高胶囊，金 / 靛蓝 / 绿三套渐变，宽度过渡 .4s。
- 模态 Modal：默认 620、色卡 760；最大 82vh；深色遮罩 + 6px 模糊；Esc 或点遮罩关闭；入场 rise .18s。
- Toast：右下角、最多 4 条，左侧四种色条，滑入 .2s，点击关闭。
- 命令面板：`⌘K` 打开，560 宽；搜索视图 / 阶段 / 生成 / 锁定 / 项目，↑↓ 选择、Enter 执行、Esc 关闭。
- 辅助组件：表格（sticky 表头）、审稿清单、技能约束项、色卡 swatch、DAG 节点与闸口、键值行。

## 布局栅格

- App：236px 左栏 + 1fr 主区；顶栏 54px；内容区独立滚动。
- 流水线：268px 阶段列表 + 1fr 工作区；工作区内 1fr + 336px 右栏。
- 画布：1fr 画布 + 300px 运行状态栏；DAG 节点 178×84，列距 212、行高 208，背景 26px 点阵。
- 镜头：表格 1fr + 380px 详情栏；资产库用 3 列网格。
- 内边距 14–22px；桌面窗口 1440×940，最小 1080×720。
- 响应式：≤1180px 右栏折到下方；≤900px 隐藏左栏（`--rail: 0`）、流水线单列、阶段列表限高 240。

## 交互与动效

- 时长统一短促：hover / 焦点 150ms，遮罩 160ms，模态 180ms，Toast 200ms，进度 400ms；曲线用 `ease` 或 `cubic-bezier(.2,.8,.3,1)`。
- 状态用色不用阴影：锁定绿、待审琥珀、跳过灰、打回红；金色只给主操作与选中。DAG 节点用阴影表达层级，锁定 / 待审用边框色。
- 危险操作红底红字；只有「重置演示数据」弹原生 confirm，其余操作不打断。
- 焦点：输入框金色 1px 边 + 3px 10% 金色光晕；按钮按压下移 1px；DAG 节点 hover 上浮 2px。
- 动效以入场与反馈为主；仅待审批闸口有 2.4s 循环脉冲；未接入 `prefers-reduced-motion`（`Settings.reduceMotion` 已预留）。
- 文案：动词开头、短句；错误提示给下一步，如「预算不足，已挂起」。

## 图标规范

- 24×24 viewBox；`stroke=currentColor`，线宽 1.6，圆头圆角；尺寸随场景 11–17px，按钮内 14px。
- 自绘 33 个 `IconName` + 1 个 `LogoMark`（2.1 线宽、金色渐变底），共 34 个 SVG，不引入图标库。
- 命名按语义（lock / unlock / shield / spark / wallet），不按形状；状态图标固定：check 绿、eye 琥珀、x 灰、dots 琥珀。
- 网格对齐：关键笔画落在 2px 整数倍上，保证小尺寸清晰。
