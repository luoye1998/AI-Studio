# 设计系统 v2

> 2026-11 重做。目标：从「工具感」走到「工作室感」——近单色墨黑、象牙白文字、香槟金只做点缀、衬线体承担品牌与数字。

## 1. 三条原则

1. **颜色克制到近乎单色**。整屏只有墨阶 + 象牙白，香槟金只出现在「当前选中 / 关键数值 / 品牌」三处，绝不铺满。
2. **衬线负责气质，无衬线负责效率**。品牌名、页面标题、统计数字用衬线（Georgia / Songti SC）；正文、按钮、表格用无衬线。
3. **层次靠留白与细线，不靠阴影与色块**。卡片只有 1px 的 `--hair` 边框；阴影仅用于浮层和画布节点。

## 2. 令牌

### 墨阶（背景）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ink-0` | `#08080A` | 应用底色 |
| `--ink-1` | `#0C0C0F` | 侧栏 |
| `--ink-2` | `#111114` | 卡片 |
| `--ink-3` | `#16161A` | 浮层 / 侧面板 |
| `--ink-4` | `#1C1C21` | 悬停态 |

### 线与字

| 令牌 | 值 | 用途 |
|---|---|---|
| `--hair` | `rgba(255,255,255,.055)` | 常规分隔 |
| `--hair-2` | `rgba(255,255,255,.10)` | 可交互边界 |
| `--hair-3` | `rgba(255,255,255,.16)` | 悬停边界 |
| `--ivory` | `#F5F2EA` | 标题 / 强调文字 |
| `--text` | `#E6E2D9` | 正文 |
| `--muted` | `#A7A29A` | 次要文字 |
| `--dim` | `#6D6961` | 标签 / 辅助信息 |

### 语义色（全部低饱和）

| 令牌 | 值 | 语义 |
|---|---|---|
| `--gold` / `--gold-hi` | `#C8A56C` / `#E6CB98` | 品牌、当前选中、关键数值 |
| `--teal` | `#58B8A6` | 已锁定 / 成功 |
| `--amber` | `#D79A52` | 待审阅 / 警告 |
| `--rose` | `#C76E6E` | 风险 / 打回 |
| `--iris` | `#8B93C4` | 进行中 / 信息 |

每个语义色都配一个 `-wash` 版本（同色 10% 透明度），只用于底色。

## 3. 字体与字阶

| 用途 | 字体 | 字号 / 行高 |
|---|---|---|
| 品牌名 | `--serif` | 17 / 1.1 |
| 页面标题 | `--serif` | 27 / 1.15 |
| 区块标题 | `--serif` | 19 |
| 统计数字 | `--serif` | 26 |
| 正文 | `--sans` | 14 / 1.65 |
| 次要 | `--sans` | 12.5 |
| 标签 | `--sans` | 9.5，字距 .24em，全大写 |
| 数字 / 时间码 | `--mono` | tabular-nums |

## 4. 圆角与间距

- 圆角：`6 / 9 / 12 / 16 / 22`（tag 用 99px 胶囊）
- 间距：4 的倍数，卡片内边距 20，页面横向 34
- 栅格：侧栏 252px，主区自适应，右栏 352px

## 5. 组件

| 组件 | 规格 |
|---|---|
| 主按钮 | 象牙白渐变底 + 深墨字，高 34（`sm` 29 / `lg` 40） |
| 次按钮 | 透明底 + `--hair-2` 边 |
| 标签 | 胶囊，23px，语义色只染文字与边，不填满 |
| 卡片 | `--ink-2` 底 + `--hair` 边 + 16px 圆角 |
| 阶段条目 | 左图标瓦片（30×30）+ 名称 + 两行摘要 + 右状态图标 |
| 画布节点 | 左侧 2px 状态条（锁定青 / 待审琥珀） |
| 时间线 | 40px 高色带，按镜头秒数等比分宽 |

## 6. 图标

- 统一使用 **Lucide**（24 网格、1.5 描边、圆头），不再手绘
- 九阶段各有一个专属意象：靶心 / 人群 / 地球 / 目录树 / 文稿 / 心率 / 画框叠层 / 面具 / 光圈
- 图标颜色跟随语义：默认 `--dim`，选中 `--gold-hi`，锁定 `--teal`

## 7. 动效

- 时长 150–220ms，缓动 `cubic-bezier(.2,.8,.3,1)`
- 只动 `opacity` / `transform` / `border-color`
- 闸口待审批做 2.6s 呼吸光圈；其余不加循环动画

## 8. 反模式（明确不做）

- 大面积金色或渐变霓虹
- 卡片带彩色描边（改用左侧状态条）
- 12px 以下正文
- 图标混用不同描边宽度
- 阴影堆叠（只有浮层允许）
