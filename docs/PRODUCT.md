# WorkStream Studio 产品说明

> 把短剧 / 漫剧从灵感到成片的九阶段生产线：锁稿、闸口、预算先行。
>
> 版本 0.1.0 · Web + Electron 桌面壳 · 单机本地运行

## 定位与用户

WorkStream Studio 是短剧 / 漫剧团队的生产工作台：左侧九阶段流水线，中间阶段工作区，右侧硬规则、技能与上游定稿。每个阶段只做一件事——产出、审阅、锁稿，再进下一环。

- 1–5 人小团队，编剧 / 导演 / 制片常是同一批人；
- 有 AIGC 工具经验、但缺稳定交片流程的创作者；
- 需要把方法、资产、成本、审计留在同一项目的独立工作室。

## 四个真实痛点

| 痛点 | 现场 | 解法 |
|---|---|---|
| 上下文串戏 | 一个对话框写人设、剧本、分镜，草稿被当定稿，改人设全片飘 | 九阶段隔离，下游只拼锁定上游，草稿不进上下文 |
| 人物变脸 | 重抽一次换张脸，十张图放一起露馅 | 四视图、多角度场景、LIRA 色卡，定稿版本作镜头锚点 |
| 台词与时长打架 | 38 字台词塞 6 秒镜头，话没说完就切 | 08 先算台词秒数（4.2 字/秒 ×1.18），超时长标红 |
| 素材散落 | 提示词在聊天、图在网盘、账单在表格 | 项目内聚合脚本、资产、镜头、成本、日志 |

## 核心机制

### 九阶段流水线

| # | 阶段 | 交付物 |
|---|---|---|
| 01 | 概念锚定 | 故事立项书 |
| 02 | 角色圣经 | 角色档案卡 |
| 03 | 世界观 | 世界观设定集（可跳过） |
| 04 | 分场大纲 | 分场表 |
| 05 | 正式剧本 | 定稿剧本 |
| 06 | 剧本压力测试 | 体检诊断报告（可跳过） |
| 07 | 图像资产 | 角色卡 / 场景图 / 道具图（约 ¥24） |
| 08 | 表演设计 | 表演指导表 |
| 09 | 镜头与视频提示词 | 分镜表 + 视频提示词 |

基准估算 ¥1–24，技能最多上浮 36%；07 最贵，先写对字再生图。

### 锁稿铁律

- 只有 `locked` 阶段进入下游提示词，草稿、待审稿不喂。
- 锁定后正文只读、禁止再生成；解锁会把其后所有锁定阶段退回 `review`。
- 每次生成 / 采用都进版本历史，重跑不覆盖，单阶段最多 20 版。
- 05 锁稿触发 G1，09 锁稿触发 G2。

### 三级锁定

| 层级 | 锁什么 | 代码锚点 | 触发 |
|---|---|---|---|
| 资产锁 | 角色、场景、道具、风格的定稿 | `Asset.approvedVersionId` | 资产库「定稿」 |
| 阶段锁 | 九个阶段的定稿正文 | `StageState.status='locked'` | 阶段页「确认采用」 |
| 成片锁 | 09 镜头与最终交付 | `cinedance` 锁稿 → G2 | 终审通过 |

### 人工闸口 G1 / G2

| 闸口 | 位置 | 通过 | 打回 |
|---|---|---|---|
| G1 剧本定稿 | 05 锁稿后 | 剧本成铁律，继续下游 | 记问题项，05 退回审阅 |
| G2 成片终审 | 09 锁稿后 | 进入交付 | 退回 09 重审 |

打回需至少一条问题项，可标记 `affected` / `node` / `all` 重跑范围。

### 预算闸口：80% 提醒，100% 硬停

- 单价：文本 ¥0.8、图像 ¥2、视频 ¥12、合成 ¥2.5。
- 80%：余额不足两成时，顶栏转琥珀提醒。
- 100%：阶段生成先验算；扣费会让余额为负则不扣费、不生成，挂预算闸口等审批；通过追加 20%，打回退回审阅。
- 资产与镜头生成也先验算，不足只拒绝并提示。

## 页面地图

| 页面 | 作用 | 关键交互 |
|---|---|---|
| 流水线 | 九阶段、编辑预览、审稿清单、版本历史；右栏需求 / 技能 / 上游 | 生成、锁稿、解锁、跳过、去审批 |
| 画布视图 | 节点=阶段，实线=依赖，虚线=闸口 | 点节点进阶段、点闸口审批 |
| 资产库 | 角色 / 场景 / 道具 / 风格、四视图、24 套色卡 | 加资产、生版本 ¥2、定稿、挂色卡 |
| 镜头 | 分镜表 + 详情 + 编译提示词 | 批量 ¥12/镜、单镜重做、通过、改秒数 |
| 成本与预算 | 预算 / 已花 / 剩余、闸口、消费明细 | 改预算、导出 CSV |
| 剧本知识库 | 挂载目录、三种配合方式、文档启停 | 桌面选目录、切模式 |
| 设置 | 模型通道、数据与关于 | 配模型、导工程 JSON、打印、重置 |
| 闸口审批（模态） | 审稿清单、审批意见、问题项、重跑范围 | 通过 / 打回 |

`⌘K` 命令面板，`⌘1`–`⌘6` 切主视图。

## 与竞品的差异

- TapNow：都做预估消耗与重跑不覆盖；WorkStream 把超支变成流程挂起和人工审批。
- LibTV：都用阶段闸门约束画布；WorkStream 的画布只是同一份流水线状态的可视化，不另建运行模型。
- WorkRally：都有项目—场次—资产库三层；WorkStream 让资产成为提示词锚点，与色卡、锁稿共同约束生成。

## 能力边界（0.1.0）

- 无真实模型调用：没有网络请求，生成由 `mockGenerate` 本地推演，可编辑，但不代表模型质量。
- 费用是本地估算与记账，不对应真实账单。
- 数据存 `localStorage`（`workstream-studio-v1`），无账号、云同步与多人协作。
- 知识库尚未真正检索，文档内容不进入提示词，列表为示例数据。
- 不产出真实图片 / 视频，没有合成、剪辑与成片导出。
